# MindTrace v1.0.0

MindTrace 的首个正式版本。从这一版开始，记录、时间线、知识库、研究四块能力真正连成一条可回溯的链路：写下的东西能查、能改、能追到来源，也能按需隐去。

相比 v0.4.x，v1.0.0 带来知识库整理能力、时间线全量回溯、对话与时间线合并、平台账号关联、研究页整合，以及一次彻底的 AI 模型清单改造和界面自适应重做。

## 主要更新

### 知识库查看与整理

- 文档类资料支持排版预览，正文中的图片一并显示。
- 导入 Markdown、TXT、HTML、Word、PPT、Excel 时，图片会存进本地数据目录，源文件删除后仍可查看。
- 文件夹支持改名、加标签、按住拖动排序，并显示创建时间。
- 资料标题可手动修改，也可以让 AI 按正文拟定；两者都需要确认后才写入。
- 确认过的标题不再被正文内容覆盖，避免手工命名被冲掉。
- 删除文件夹与资料改用应用内确认框，删除成功后右下角给出短暂浮窗提示。
- 系统文件夹一律不允许删除。
- AI 快速记录生成的资料正文改为只读，修改统一走保存流程。
- 保存修改与保存感受只在内容真正发生变化时才提示成功，不再出现无变化也报“已保存”的假反馈。
- 知识库页面不再整页滚动，文件夹过多时只在面板内部滚动，操作提示不再顶在页面顶部。

### 时间线全量回溯

- 记录详情可以直接修改发生日期与时间，清空时间即回到“未标时间”。
- 知识库的收录、修改、写感受、AI 总结、导入与删除，会按天进入时间线。
- 历史资料会回填收录事件，旧资料也能查到来源。
- 时间线内可以只读预览资料的更改时间、标题与内容，要修改则通过按钮进入知识库页面。
- 记录、知识操作与对话会话支持三种范围的隐去，默认连搜索、报告和趋势一起隐去。
- 隐去只影响展示，内容不删除；入口显示被隐去的数量，并可逐行恢复。
- 记录与资料的关联改以来源记录编号为准，修复在时间线保存记录后知识库跳转失效的问题。
- 睡眠同日冲突检查仍然计入已隐去的记录，不会因隐去而放过冲突。

### 记录页历史对话

- 会话作为“AI 对话”条目按最近消息时间并入时间线，点击可回看完整原文。
- 归档时支持三种标题方式：保持默认、手动填写、让 AI 生成。
- 记录页显示当前对话累计 Token，余额提示暂为占位。
- 新增会话元数据表并回填旧数据，历史对话不会丢失。
- 修复归档时把每条消息拆成独立会话的问题。

### 平台账号关联

- 新增 GitHub 与 Gitee 账号关联。
- 令牌只在本机直连平台官方接口校验，不经过任何中转服务。
- 以平台返回的不可变账号 ID 作为唯一性依据，同一平台只允许关联一个账号。
- 换绑必须先解除关联；令牌使用系统加密能力保存。
- 新增本机身份指纹，账号集合变化即变化，默认隐藏，由卡片右上角开关控制。
- 账号 ID 不再写入诊断日志，界面不再加载平台头像，避免打开页面就产生外发请求。

### 研究页整合

- 报告页更名为“研究”，引导式周度研究从实验室迁入。
- 新增“本周研究需求”，AI 必须按需求出题。
- 需求为空时先弹确认，需求改动后提示需要重新生成。
- 去搜索改走系统浏览器打开。

### AI 模型清单改造

- 不再依赖硬编码的预设模型：优先用 Base URL 与 API Key 调用服务商的模型清单接口，获取实时可用模型。
- 内置预设降级为离线兜底，仍可在无网络或未授权时使用。
- 预设模型清单外移到独立配置文件，后续更新模型只需改配置，不必改代码或重新发版。
- 模型来源会在设置页明确标注：来自服务商实时返回时显示为正向反馈，仍是内置预设时标注“可能已过期”并提供拉取入口。
- 设置页字段顺序调整为 Base URL → API Key → 模型，与“先填 Key 再拉模型”的实际操作顺序一致。
- 未填写 API Key 时拦截模型拉取并给出提示。
- 首次遇到已配置 Key 且从未刷新过的情形会自动拉取一次，失败不打扰用户，也不反复重试。
- AI 请求失败时给出分类提示，覆盖模型下线、鉴权失败、限流、网络、服务端与未知六类，每类附带中文原因说明和建议操作。
- 内置预设同步更新到各家当前版本，替换已下线的模型。

### AI 技能中心

- AI 技能按“AI 快速记录、日报、周报、周度研究”四个区域隔离。
- 技能只注入所属区域的提示词，不会串到其他区域。
- 注入前先声明输出契约，并限制单区域启用数量与注入长度。
- 设置页新增技能中心，各区域顶部提供内联的查看与添加入口。
- 技能只改提示词，不新增数据写入路径，原有内容校验闸门保持不变。

### 界面自适应与视觉

- 侧栏宽度、内容内边距与内容列宽随窗口尺寸变化。
- 宽屏下放宽内容列，设置页改为两栏布局。
- 窄屏与矮窗口分别收敛，窗口本身设置了最小可用尺寸。
- 统一圆角、投影、背景渐变与键盘焦点环。
- 滚动区域预留滚动条占位，内容增减时不再抖动。

### 工程与仓库治理

- 跨进程共享类型统一落位，消除数据库层与页面层的重复类型定义。
- 数据库、导入、适配器、分析、技能与基础工具模块的导出范围收窄，内部实现不再外泄。
- 时间线纯转换与分组逻辑抽出并补充回归测试。
- 新增架构结构基线文档，明确新代码落位规则、导出准入与删除准入规则。
- README 重写为面向用户的产品介绍，补充真实运行界面截图。
- 修正忽略规则，避免数据目录被选到仓库内时把数据库与密钥文件提交上去。

## 数据兼容性

- 现有时间线记录、知识资料、AI 对话、报告、个人资料与设置都会保留。
- 数据库在启动时自动增量迁移：新增表用“不存在则创建”，新增字段先检查再添加，不要求用户手动操作。
- 历史 AI 会话会回填为会话元数据，历史知识资料会回填收录事件。
- 旧版睡眠记录仍可读取，并明确标记为“分段未知”，不会伪造起止时间。
- API Key、数据库、备份与设置仍保存在本机；正常应用更新不会清除用户数据目录。
- v0.4.0 内置的应用更新模块可以正常检测到本版本，无需手动卸载重装。

## 如何升级

`v0.4.0` 及更早的 `v0.3.0` 都可以通过应用左下角的更新入口检查并下载 `v1.0.0`。也可以前往 GitHub Releases 手动下载安装，新版本会继续使用原有本地数据目录。

安装文件：`MindTrace-Setup-1.0.0.exe`

## 下载文件说明

Release 页面中的 Assets 包含以下文件：

- `MindTrace-Setup-1.0.0.exe`：Windows 10/11 x64 安装程序。普通用户只需要下载并运行这个文件。
- `MindTrace-Setup-1.0.0.exe.blockmap`：应用自动更新使用的差分索引文件，用于判断安装包中发生变化的数据块。普通用户不需要手动下载或打开。
- `latest.yml`：应用自动更新使用的版本清单，包含最新版本号、安装包名称、文件大小和完整性校验信息。普通用户不需要手动下载或修改。
- `Source code (zip)`：GitHub 自动生成的当前版本源码压缩包，适合需要查看或自行构建源码的开发者，不是可直接安装的应用。
- `Source code (tar.gz)`：与 ZIP 内容相同的源码归档，主要面向习惯使用 TAR 格式的开发者，同样不能直接作为 Windows 安装程序使用。

普通用户请选择：

```text
MindTrace-Setup-1.0.0.exe
```

`.blockmap` 和 `latest.yml` 必须与安装包同时保留在 Release 中，否则应用内版本检测、增量下载或安装包完整性校验可能无法正常工作。
