# MindTrace v0.3.0

这是一次以“记录 → 知识库 → 我的 → 分析”为核心的可用性整合升级。除界面重构外，本版本还补齐了知识流、个人资料、数据迁移、语义搜索和应用内更新能力。

## 主要更新

### 记录与知识库打通

- 手动直录中，除睡眠外的记录可以选择“同时加入知识库”。
- 收录时可以选择已有文件夹，也可以直接创建新文件夹；文件夹重命名和删除仍统一在知识库页面完成。
- 记录与知识条目采用事务保存，避免只保存一半的数据。
- 知识条目保留来源记录信息，但知识库副本可以独立编辑或删除，不会破坏时间线原记录。
- AI 快速记录的非睡眠条目默认加入“AI 快速记录”系统文件夹，确认前可以逐项取消或更换文件夹。
- 系统文件夹支持改名；删除后会在需要时自动重建，避免产生重复文件夹。

### AI 快速记录与个人资料

- AI 快速记录改为一个可跨重启恢复的持久会话。
- 支持“清空并新建”，只清除当前对话，不删除已归档记录和知识资料。
- AI 请求使用有限历史上下文，避免会话无限增长。
- AI 解析继续遵守六类记录契约，并限制编造用户经历或覆盖手填资料。
- AI 可以从首次有效对话生成个人资料草稿，但必须由用户逐项确认后才写入。
- 手动填写的名称、称呼、职业/身份、所在地、个人简介、关注目标和兴趣优先，后续 AI 不会覆盖。

### AI 对话导入调整

- “导入 AI 对话”入口从设置页移动到知识库页面。
- 每个完整会话保存为一条知识资料，进入“AI 对话导入”系统文件夹。
- 时间线只生成一条会话摘要，不再拆成大量逐消息记录。
- 摘要可以跳转到对应知识条目；资料被删除时会显示明确状态。
- 使用稳定导入标识去重，重复导入同一会话不会重复创建资料或时间线摘要。
- 摘要使用确定性文本生成，不消耗 AI 配额，也不要求 API Key。

### 新增“我的”页面

- 新增个人资料编辑与 AI 草稿确认区域。
- 集中展示睡眠趋势、负面事件趋势和日期范围筛选。
- 原本不适合作为实验功能的固定个人指标从实验室移入“我的”。
- 实验室保留引导式周度研究等真正具有探索性的能力。

### 更安全的数据目录迁移

- 设置页可以选择新的数据目录，不再只能使用默认 C 盘位置。
- 迁移前检查目录是否为空、是否可写、剩余空间是否足够，并显示源目录、目标目录和数据量。
- 用户确认后才复制数据，并逐文件校验大小和 SHA-256。
- 校验成功后原子写入新目录配置，下次启动才正式切换。
- 迁移失败不会切换路径；旧目录不会自动删除，并保留打开旧目录的入口。
- 新目录不可用时阻止静默创建空数据库，并允许恢复使用迁移前目录。

### AI 服务与搜索能力

- 提供商预设带有内置常用模型列表，选择预设后无需 API Key 即可先选择模型。
- “刷新账户可用模型”按服务实际要求处理鉴权；Ollama 等本地服务可以无 Key 刷新。
- 鉴权失败会直接显示服务端错误，不再被前端统一拦截。
- 新增 Embedding 语义搜索、长文本分块索引和命中片段返回。
- 新增全文检索与语义搜索的 RRF 混合检索。
- 支持 AI 查询扩展和 LLM 精排，提高复杂问题的检索相关性。

### UI/UX 与桌面体验

- 重构记录、时间线、报告、知识库、设置、实验室和“我的”页面视觉体系。
- 支持浅色、深色和跟随系统主题。
- 移除 Electron 默认的 File / Edit / View / Window 菜单栏。
- 新增与应用主题一致的自定义标题栏和最小化、最大化、关闭按钮。
- 改善浅色模式下窗口按钮的悬停反馈，并移除导航项悬停下划线。
- 设置固定在左下角，本地优先提示和主题切换位于其上方。
- 导航栏支持调整顺序；进入调整模式后长按项目即可上下移动，顺序会保存在本机。
- 改进新版 BAT 启动流程、窗口聚焦和启动说明。

### 应用内版本检测与更新

- 正式安装版启动后会检查 GitHub Release，并定期重新检查。
- 最新版本显示“已是最新版本 vX.X.X”；有新版时显示“更新到最新版本”。
- 按钮下方显示检查、下载进度、下载完成和失败原因，不额外增加永久按钮状态。
- 下载完成后由用户确认是否立即重启安装，不会在记录过程中突然退出。
- 安装更新前自动备份本地数据库，更新程序文件不会删除知识库、时间线、API Key 或个人资料。
- BAT、`pnpm dev` 和 `electron .` 启动的开发模式不会自动替换程序，也不会执行 `git pull`。

## 数据兼容性

- 现有记录、知识条目和历史导入内容会保留。
- 数据库升级使用兼容、幂等迁移，不要求用户手动重建数据库。
- API Key、数据库、资料和设置仍保存在本机；正常应用更新不会迁移或清除用户数据目录。

## 如何升级

`v0.2.0` 尚未内置自动更新模块，因此需要手动下载并安装一次 `v0.3.0`。从 `v0.3.0` 开始，后续版本可以通过应用左下角的更新入口完成检查和下载。

安装文件：`MindTrace-Setup-0.3.0.exe`
