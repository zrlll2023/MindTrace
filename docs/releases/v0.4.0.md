# MindTrace v0.4.0

这是一次以“记录更准确、归档更可靠、回看更清晰”为核心的体验与可靠性升级。本版本重点完善 AI 快速记录、时间线和知识库之间的写入流程，同时补充发生时间、睡眠分段、报告导出、实验室草稿持久化和诊断能力。

## 主要更新

### AI 快速记录归档与撤回

- AI 解析结果保存时，会通过统一事务写入时间线和所选知识库，避免只保存一部分数据。
- 修复 Vue 响应式数据无法通过 Electron IPC 传输，导致 AI 快速记录不能加入时间线和知识库的问题。
- 保存成功后不再清空 AI 解析内容，原有卡片会继续保留，方便核对本次归档结果。
- 保存按钮会变为不可重复点击的“已保存”状态，并显示本次写入时间线和知识库的数量。
- 新增一键撤回，可以同时撤销本次生成的时间线记录和关联知识资料。
- 撤回后保留原解析内容，可以调整日期、时间、类型或知识库选项后重新保存。
- 已保存状态和关联记录编号会持久化，重新打开应用后仍可以识别和撤回。
- 保存、撤回或 AI 解析进行期间会阻止清空对话，避免并发操作造成状态不一致。

### AI 快速记录对话体验

- 为用户消息和 AI 回复增加时间显示，方便确认对话与记录的先后顺序。
- 每次进入 AI 快速记录页面时自动定位到最新对话，不再默认停留在最早内容。
- “清空并新建”改为应用内确认窗口，与现有主题、按钮和弹层风格保持一致。
- 清空完成后自动恢复输入焦点，可以立即开始新的记录。
- 修复清空对话后输入框无法继续输入的问题。
- AI 请求尚未完成时如果对话已经被清空，过期回复会被忽略，不再重新插入新会话。
- 调整输入区域的边框、背景、焦点状态和间距，使其与记录页面整体视觉保持一致。

### 发生时间与时间线

- AI 解析结果和手动记录都可以分别选择“发生日期”和“发生时间”。
- 新增小时与分钟滚轮选择器，分钟保持五分钟精度。
- 滚轮方向调整为向下增加时间、向上减少时间，符合常见操作直觉。
- 时间线优先显示内容实际发生的时间，不再将数据库保存时间误认为发生时间。
- 同一天的记录按照发生时间排序；未填写时间的记录仍保留并显示为“未标时间”。
- 记录详情会同时展示发生时间、保存时间和 AI 解析置信度。
- 修正本地日期计算，避免时区差异导致“今天”“昨天”或默认日期出现偏移。
- 优化 AI 解析类型切换和内容校验，无效或不完整的记录不会进入归档流程。

### 睡眠记录与趋势

- 睡眠记录支持“时间段”和“当天累计”两种录入方式。
- 时间段模式可以同时选择日期、入睡时间和结束时间，并自动换算睡眠时长。
- 当天累计模式只记录总时长，不会错误推断连续睡眠时间。
- 时间线会按天聚合睡眠记录，展示睡眠总时长、分段数量和最长连续睡眠时间。
- 可以从睡眠汇总进入分段详情，查看并更正具体睡眠记录。
- “我的”页面会区分分段睡眠、当天累计和旧版仅时长记录。
- 生活趋势计算不再把缺失睡眠数据当作零，也不会对分段未知的记录推断连续性。
- 日报和实验室分析会获得明确的睡眠数据模式，避免将累计睡眠误写成连续睡眠。

### AI 快速记录知识库目录

- “AI 快速记录”改为具有固定系统标识的知识库目录。
- 系统会根据内部标识识别该目录，不再只依赖可变的显示名称。
- 系统目录被异常删除后，会在进入知识库或再次归档时自动重建。
- 历史同名目录会升级为系统目录，并保留其中已有资料。
- 不再允许重命名或删除“AI 快速记录”系统目录。
- 不再允许手动创建同名目录，包含不同空格形式的名称也会被识别并阻止。
- 系统目录不支持手动新增资料、文件导入或 AI 延伸，避免自动记录与普通资料混用。
- AI 快速记录写入知识库后的资料类型由“记录”调整为“AI 记录”。

### 知识资料编辑可靠性

- AI 快速记录生成的知识资料仍然可以修改正文、收录原因和个人感受。
- 修复资料不存在或数据库没有完成更新时，页面仍然显示“已保存”的假成功问题。
- 保存正文和保存感受分别显示独立状态，不再共用同一个成功提示。
- Electron 接口会返回数据库重新读取的资料，页面核对内容一致后才显示保存成功。
- 资料已被删除或持久化结果不一致时，会保留当前输入并显示具体错误。
- 修改 AI 记录正文时，知识库列表摘要会同步更新。
- 更新列表摘要时保留“事件”“对话”“句子”“想法”或“记录”等原类型前缀。
- 知识资料副本的修改仍不会反向覆盖时间线中的原始记录。

### 知识库文件导入

- 完善 Markdown、TXT、HTML、Word、PPT 和 Excel 文件的本地文本提取与导入。
- 文件导入失败时会显示具体文件名和失败原因，不再只显示笼统错误。
- 导入完成后会报告成功数量和失败数量。
- AI 快速记录系统目录不会出现在普通归档目标中，也不会接受文件导入。

### 报告导出与显示

- 报告导出支持配置固定保存目录，并可以恢复默认导出位置。
- 未配置固定目录时仍会显示保存位置选择窗口。
- 导出完成、取消或失败时会显示明确状态。
- 日报和周报生成内容统一使用宋体。
- 报告原有字号、行高、标题层级、列表和表格布局保持不变。
- 页面导航、存档列表、日期选择器和操作按钮继续使用原有界面字体。

### 实验室、设置与诊断

- 引导式周度研究的阶段、搜索计划、候选资料和用户选择会保存在本机。
- 离开实验室页面或重启应用后，可以继续上次未完成的研究流程。
- 新增统一的选择控件和可搜索组合框，改善提供商、模型和其他选项的使用体验。
- 完善数据目录迁移后的恢复、撤销和异常目录处理。
- 新增本地运行日志、日志目录打开、诊断包导出和日志清理能力。
- 渲染进程崩溃、页面加载失败和后台任务异常会写入诊断日志。
- 优化应用更新状态显示，并补充失败原因和重新检查入口。

## 数据兼容性

- 现有时间线记录、知识资料、AI 对话、报告、个人资料和设置都会保留。
- 数据库会自动增加 AI 快速记录撤回所需的关联字段，不要求用户手动迁移。
- 历史“AI 快速记录”同名目录升级为系统目录时会保留其中已有资料。
- 旧版睡眠记录仍可读取，并明确标记为“分段未知”，不会伪造起止时间。
- API Key、数据库、备份和设置仍保存在本机；正常应用更新不会清除用户数据目录。

## 如何升级

`v0.3.0` 已经内置应用更新模块，可以通过应用左下角的更新入口检查并下载 `v0.4.0`。也可以前往 GitHub Releases 手动下载安装，新版本会继续使用原有本地数据目录。

安装文件：`MindTrace-Setup-0.4.0.exe`

## 下载文件说明

Release 页面中的 Assets 包含以下文件：

- `MindTrace-Setup-0.4.0.exe`：Windows 10/11 x64 安装程序。普通用户只需要下载并运行这个文件。
- `MindTrace-Setup-0.4.0.exe.blockmap`：应用自动更新使用的差分索引文件，用于判断安装包中发生变化的数据块。普通用户不需要手动下载或打开。
- `latest.yml`：应用自动更新使用的版本清单，包含最新版本号、安装包名称、文件大小和完整性校验信息。普通用户不需要手动下载或修改。
- `Source code (zip)`：GitHub 自动生成的当前版本源码压缩包，适合需要查看或自行构建源码的开发者，不是可直接安装的应用。
- `Source code (tar.gz)`：与 ZIP 内容相同的源码归档，主要面向习惯使用 TAR 格式的开发者，同样不能直接作为 Windows 安装程序使用。

普通用户请选择：

```text
MindTrace-Setup-0.4.0.exe
```

`.blockmap` 和 `latest.yml` 必须与安装包同时保留在 Release 中，否则应用内版本检测、增量下载或安装包完整性校验可能无法正常工作。

源码压缩包不包含已经构建好的 Windows 安装程序。需要从源码运行时，请按照仓库 README 中的开发者指南准备 Node.js 和 pnpm 环境。
