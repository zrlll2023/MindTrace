# MindTrace 用户手册

MindTrace 是一个**本地优先**的桌面应用：把你的生活随手倒进一个聊天框，AI 帮你拆解归档、发现规律、生成日报/周报。你的原始数据永远保存在自己电脑上。

---

## 1. 安装与首次启动

1. 运行 `MindTrace Setup x.y.z.exe`，按提示完成安装（可选择安装目录）。
2. 启动 MindTrace，左侧导航栏包含四个页面：**记录 / 时间线 / 报告 / 设置**。

## 2. 首次配置（必做）

进入 **设置** 页：

1. **选择提供商预设**（DeepSeek / 智谱 GLM / Moonshot Kimi / SiliconFlow / Ollama / 自定义），选中后 Base URL 自动填充。
2. 选择预设后直接从内置列表选择常用模型；填写 API Key 后可点 **「刷新账户可用模型」** 获取实际列表。
3. 粘贴你的 **API Key**（可在各提供商官网申请）。
4. 点击 **「测试连接」**，显示 ✅ 后点击 **「保存设置」**。

> 🔒 API Key 使用 Windows DPAPI 加密存储在本机，永不明文落盘；换模型/换提供商随时可改。

## 3. 日常记录（核心用法）

进入 **记录** 页，像聊天一样随手写，一条消息可以混着写：

```
睡了6.5小时，被导师骂了一顿，看到一句话：纸上得来终觉浅，突然想到RAG评估好像有新方法
```

AI 会自动拆解为 4 张卡片：😴 睡眠 6.5h / 😞 事件 / 📖 句子 / 💡 想法。你可以：

- 点卡片上的**下拉框**改类型、**直接编辑**内容
- 对 **黄色边框**（置信度 <70%）的卡片重点检查
- 不对的卡片直接**删除**
- 点 **「确认归档」** 一次保存

> ⌨️ Enter 发送，Ctrl+Enter 换行。一次记录建议在 30 秒内完成。

## 4. 查看时间线

进入 **时间线** 页：

- 左侧是一条**日期轴**，每天一个节点，自上而下由新到旧；「今天」「昨天」会直接标出，每个节点下显示星期与当天条数
- 右侧是当天的记录条目：**时间 + 类型 + 摘要**，点条目从右侧打开详情
- 顶部**类型筛选**（睡眠 / 事件 / 对话 / 句子 / 想法 / 其他）各带一种语义色，点击选中、再点取消
- 选择**日期范围**过滤；搜索框支持**全文检索**，勾选「混合」则叠加语义检索（需在设置页启用 Embedding）
- 点任意条目打开详情：**原始记录只读**（永不篡改），结构化内容可修正保存

## 5. 日报与周报

进入 **报告** 页：

- **每天首次打开应用**时，AI 自动生成昨日/今日日报（有记录才生成）
- **日报 / 周报** 两个 Tab；左侧为归档列表，点开即读
- 选一个日期点 **「生成该日日报」/「生成该周周报」** 可随时手动补生成
- 日报结构：今天概况 / 规律与洞察 / 兴趣线推进 / 明日建议——AI 会自动检索你的历史记录、跟踪你的兴趣线（如"RAG 学习线"）、计算睡眠与情绪的相关性
- 点 **「导出 Markdown」** 保存到 `数据目录/exports/`

## 6. 导入 AI 对话

在 **知识库 → 导入 AI 对话**：

1. **ChatGPT**：网页版 → 头像 → Settings → Data Controls → **Export data** → 等待邮件 → 下载 ZIP（勿解压）
2. **Claude**：Settings → **Privacy** → Export data → 下载 ZIP
3. 回到 MindTrace，点 **「选择导出 ZIP 并导入」**

每个完整会话会成为“AI 对话导入”文件夹中的一份知识资料；时间线只保留一条摘要并可跳回完整会话。自动去重——同一份 ZIP 重复导入不会产生重复资料。

## 7. 数据安全与备份

- 所有数据保存在本地数据目录（设置页可查看路径并一键打开）：
  - `mindtrace.db` —— 数据库（全部记录）
  - `backups/` —— 每日自动备份，默认保留 30 份（超出自动删最旧）
  - `exports/` —— 导出的 Markdown 报告
  - `secrets.bin` —— 加密的 API Key
- **恢复方法**：关闭应用，把 `backups/mindtrace-某日期.db` 复制回数据目录并重命名为 `mindtrace.db`，重新打开即可。
- 出网脱敏开关（默认开启）：发送给 AI 分析前去除人名、账号等标识信息。原始数据永远不出你的电脑。

## 8. 外观与主题

MindTrace 提供两套主题，随时可切换：

- **纸 · 浅色**：暖白纸面，适合白天阅读
- **墨 · 深色**：近黑墨底，适合夜间记录，长时间写不刺眼
- **跟随系统**：随 Windows 的浅色/深色模式自动切换（默认）

两种切换入口：

1. 左侧栏底部的**主题按钮**（☀ / 🖥 / ☾ 三个图标，点击即切）
2. **设置 → 外观**：带缩略图预览，选一个点一下即可

选择会记在本机，下次启动保持。

## 9. 我的与个人资料

“我的”页面集中展示名称、称呼、职业/身份、所在地、个人简介、关注目标、兴趣，以及睡眠和负面事件趋势。手动资料始终优先；AI 快速记录识别到资料时只生成待确认草稿，不会覆盖手填内容。

## 10. 数据目录迁移

在 **设置 → 数据** 选择“更换数据目录”。应用只接受空且可写、空间充足的目标目录；确认后复制全部数据并逐文件校验，重启后切换。旧目录不会自动删除，可用于回滚。

## 11. 常见问题

**Q：日报没有自动生成？**
当天没有任何记录，或 AI 未配置/网络失败。补录数据后到报告页手动生成即可。

**Q：导入 ZIP 提示「无法识别」？**
确认下载的是官方 Export 的原始 ZIP（不要解压后再压缩）；ChatGPT 的 ZIP 内含 `conversations.json`，Claude 的同名文件结构不同，应用会自动识别。

**Q：解析出来的类型不对？**
在确认卡片上直接改类型/编辑内容再归档；归档后也可在时间线详情里修正结构化内容。

**Q：想换一个 AI 提供商？**
设置页换预设 → 选择内置模型 → 填新 Key → 测试连接 → 保存。需要时再刷新账户可用模型，历史数据不受影响。

**Q：卸载会丢数据吗？**
数据在用户数据目录（不在安装目录），正常卸载不会删除；重装后自动接上。
